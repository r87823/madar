# قالب سجل ملاحظات pilot

## تعليمات

- سجل كل ملاحظة قبل تغيير الكود.
- لا تكتب passwords أو secrets.
- استخدم روابط screenshots أو references فقط إذا كانت لا تحتوي بيانات حساسة.
- اربط كل ملاحظة برقم UAT إن أمكن.

## التصنيفات

- bug
- workflow change
- UI/UX improvement
- missing feature
- permission issue
- report issue
- accounting issue
- performance issue
- training/documentation issue

## الأولويات

- blocker: يمنع pilot أو production.
- high: يعرقل workflow مهم.
- medium: يؤثر على الاستخدام لكنه لا يمنع التشغيل.
- low: تحسين أو ملاحظة تدريبية.
